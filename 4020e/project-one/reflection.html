Reflection

For Project 1, I really went into this with adjusting the Dimension template to work as 4 separate pages, with a landing/home page, an about page, a members page, and a music page. That was the biggest hurdle I had to face, since my first attempt had the websites appear as just blank pages rather than with any of the styling choices and adjustments I had made in the CSS file. I also played around with the shared style sheet and Flexbox in order to make that Members page which kept on giving me issues when it wouldn't wrap the way that I had wanted it to. I later figured out that I was missing a few closing tags in the HTML file, which was causing the Flexbox to not work properly. I also had to adjust the CSS file to make the buttons smaller and more compact, as well as adjusting the hover effect on the members page to make it more subtle and less jarring when hovering over the member cards.

I'm especially proud of how I managed to get the Flexbox page to work properly, as it was a bit of a challenge to get it to wrap the way I wanted it to, with the wrap forcing it to work in 2 per row, and 4 in a column. I really like how it floats up and responds, and I'm glad that I got it to be more responsive. I was also pretty impressed when I managed to get the pages to look like the original articles again, with the gray square background and the text aligned to the left, since a few attempts had all three pages looking different from each other. In the future, I'd like to learn how I can add in more JavaScript to make the pages more interactive, especially since this time I just focused a lot on the css and how that could make the page more interactive
